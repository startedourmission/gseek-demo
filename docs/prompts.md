# Claude 요구사항 프롬프트 예시

강의 "Claude 활용법" 파트에서 쓰는 프롬프트입니다. 한 번에 다 보내기보다 **1 → 2 → 3 순서로** 나눠 보내면 결과가 안정적입니다.

---

## 1. 전체 구조 잡기

```
Next.js(App Router, TypeScript)와 Supabase로 회원제 홈페이지를 만들고 싶어.

[페이지]
- / : 서비스 소개 페이지 (누구나)
- /faq : 자주 묻는 질문 (누구나, DB의 faqs 테이블에서 불러오기)
- /signup : 이메일 + 비밀번호 회원가입
- /login : 이메일 로그인
- /member : 로그인한 회원만. 1:1 질문을 남기고 내 질문과 답변을 확인

[조건]
- 인증은 @supabase/ssr 사용, 로그인 안 한 사람이 /member에 오면 /login으로 보내기
- Supabase 주소와 키는 환경변수 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY로 읽기
- 오류 메시지는 한국어로

먼저 폴더 구조와 필요한 파일 목록만 알려줘.
```

## 2. 데이터베이스 + 보안 규칙

```
Supabase에 실행할 SQL을 만들어줘.

- faqs 테이블: category, question, answer, sort_order, is_published
- questions 테이블: user_id(auth.users 참조, 기본값 auth.uid()), content, answer, answered_at
- 두 테이블 모두 RLS를 켜고
  - faqs: 공개된 항목은 로그인 안 해도 누구나 조회
  - questions: 본인 질문만 조회 / 본인 이름으로만 작성 / 답변 전 본인 질문만 삭제
- 회원은 answer를 수정할 수 없어야 해 (운영자가 대시보드에서 작성)
- 예시 FAQ 데이터 5개도 넣어줘
```

## 3. 디자인 입히기

```
지금 코드의 기능은 그대로 두고 디자인만 바꿔줘.

- 분위기: 따뜻한 아이보리 종이 위에 손으로 그린 일러스트
- 색: 아이보리 배경, 차분한 클레이 주황 · 올리브 초록 · 흐린 파랑 · 갈색 계열
- 글꼴: 제목은 세리프(Noto Serif KR), 메모는 손글씨(Nanum Pen Script), 본문은 Pretendard
- 일러스트: SVG로 직접 그리되, 선은 흔들리는 잉크 느낌, 색 덩어리는 선과 살짝 어긋나게
- 스크롤 연출:
  1) 화면에 들어오면 일러스트 선이 손으로 긋듯 그려지기
  2) 섹션을 화면에 고정하고, 스크롤에 따라 "화면만 있는 사이트 → 운영되는 서비스"로 바뀌기
  3) 세로 스크롤에 맞춰 단계 카드가 가로로 흘러가기
  4) 큰 문장이 스크롤에 따라 단어별로 채워지기
- 움직임 줄이기 설정(prefers-reduced-motion)을 켠 사람에게는 애니메이션 끄기
- 모바일에서도 깨지지 않게
```

- 환경변수 이름을 미리 정해 주면, 받은 코드에 접속 정보를 넣을 위치가 분명해집니다.
- 오류가 나면 **오류 메시지 전체를 복사**해서 "이 오류를 고쳐줘"라고 보내세요.
