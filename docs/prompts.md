# Claude 요구사항 프롬프트 예시

강의 "Claude 활용법" 파트에서 쓰는 프롬프트입니다. 한 번에 다 보내기보다 **1 → 2 → 3 순서로** 나눠 보내면 결과가 안정적입니다.

> 처음부터 끝까지 따라 하는 단계별 프롬프트는 [PROMPT.md](../PROMPT.md)에 있습니다.

---

## 1. 전체 구조 잡기

```
Next.js(App Router, TypeScript)와 Supabase로 작은 쇼핑몰을 만들고 싶어.

[페이지]
- / : 상품 목록. 카테고리(?cat=주방)별 보기, 검색, 할인율 · 가격대 필터, 정렬
- /products/[id] : 상품 상세. 색상 선택, 장바구니 담기, 위시리스트
- /cart : 장바구니. 수량 변경, 상품 금액 · 배송비 · 총 결제 금액

[조건]
- 상품은 DB의 products 테이블에서 불러오기 (요청할 때마다 최신 값으로)
- 장바구니 · 위시리스트는 로그인 없이 localStorage에 저장
- 5만 원 이상 무료배송, 아니면 3,000원. 할인가는 100원 단위 반올림
- Supabase 주소와 키는 환경변수 NEXT_PUBLIC_SUPABASE_URL, NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY로 읽기
- 오류 메시지는 한국어로

먼저 폴더 구조와 필요한 파일 목록만 알려줘.
```

## 2. 데이터베이스 + 보안 규칙

```
Supabase에 실행할 SQL을 만들어줘.

- products 테이블: name, brand, category(주방 · 욕실 · 수납 · 패브릭), price, discount(할인율 %),
  rating, review_count, rank(추천 순서), color_count, badge, is_published, created_at
- RLS를 켜고
  - 공개된 상품(is_published)은 로그인 안 해도 누구나 조회
  - 추가 · 수정 · 삭제 정책은 만들지 않기 (운영자가 대시보드에서 작성)
- 예시 상품 9개도 넣어줘
```

## 3. 디자인 입히기

```
지금 코드의 기능은 그대로 두고 디자인만 바꿔줘.

- 분위기: 깔끔한 스포츠 브랜드 쇼핑몰. 흰 배경, 검정 글씨, 장식 없이
- 글꼴: Pretendard
- 색: 사진 자리와 띠는 연회색(#F5F5F5), 보조 글씨는 회색(#707072),
  할인율은 초록(#007D48), 배지는 빨강(#D33918)
- 헤더는 스크롤해도 위에 고정, 장바구니 아이콘 안에 담은 개수 표시
- 버튼은 높이 60px 알약 모양 (주 버튼 검정, 보조 버튼 회색 테두리)
- 모바일에서도 깨지지 않게
```
